The ordinary verification rerun used:

```sh
codeql test run --threads=1 --ram=2048 -J-Xmx1400m \
  --search-path=. --check-databases --keep-databases --reuse-dataset \
  m3/ql/java-tests
codeql query format --check-only m3/ql/java/*.ql m3/ql/java/*.qll \
  m3/ql/java-tests/evidence/*.ql
```

local compiler memory budget. The ordinary rerun omitted both switches and used
the resulting plans. `--fast-compilation` is supported but deprecated in the

were not treated as successful analysis. The final profile above completed.

## Verification boundary

Existing upstream implementation files are outside the change set. This work
does not run every upstream language test suite or a target application's build,
JUnit suite, or runtime. This release's semantic queries cover Java through
CodeQL's no-build extraction. External dependency resolution, full effect
closure, method-body equivalence, and other contract dimensions remain explicit
residue. Shared exported facts and close SimHash values are review candidates.

The workflow executes the Java tests, snapshot verification, QL tests, and fresh
coordinator proof on GitHub. Its current hosted status belongs to the pull
request checks and is separate from the successful local qualification above.
